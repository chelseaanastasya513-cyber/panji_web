# panji_web
Website sederhana untuk GitHub Pages dengan fitur:

- Setup
- Biaya
- Banwich
- Backend (contoh response JavaScript)

## Cara menggunakan

1. Upload file `index.html`, `styles.css`, dan `script.js` ke repository GitHub.
2. Buka `Settings` > `Pages` pada repository.
3. Pilih branch `main` dan folder `/ (root)`.
4. Simpan.
5. Akses situs Anda di `https://chelseaanastasya513-cyber.github.io/panji_web`.

## Struktur file

- `index.html`: halaman utama
- `styles.css`: styling tampilan
- `script.js`: interaksi sederhana untuk fitur backend

## Catatan

Website ini dibuat untuk hosting statis di GitHub Pages dan cocok untuk demo atau landing page sederhana.
