Panji Web

Website sederhana untuk GitHub Pages dengan fitur setup, biaya, banwich, dan backend.

Setup Biaya Banwich Backend Akses

Setup

Website ini dibuat dengan HTML, CSS, dan JavaScript. Gunakan GitHub Pages untuk hosting gratis.

  1. Buat repository baru di GitHub.
  2. Upload file index.html, styles.css, dan script.js.
  3. Aktifkan GitHub Pages di pengaturan repository.
  4. Pilih branch main dan folder / (root).

Website Anda akan muncul di https://username.github.io/repository-name.

Biaya

GitHub Pages dapat digunakan gratis untuk situs statis. Untuk website sederhana seperti ini, tidak perlu biaya bulanan.

Biaya hosting

  • GitHub Pages: Gratis
  • Domain khusus: optional, tergantung penyedia domain
  • SSL: otomatis dengan GitHub Pages
